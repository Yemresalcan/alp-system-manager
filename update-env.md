# YENİ SUPABASE BİLGİLERİNİ GÜNCELLEYIN

## .env.local dosyasını güncelleyin:

```bash
# Yeni Supabase project bilgileri
NEXT_PUBLIC_SUPABASE_URL=https://your-new-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-new-anon-key
```

## Bilgileri nereden bulacaksınız:
1. Yeni Supabase projesinde
2. Settings → API
3. Project URL ve anon public key'i kopyalayın

## Güncelleme adımları:
1. .env.local dosyasını açın
2. URL ve KEY'i değiştirin  
3. npm run dev ile restart edin
